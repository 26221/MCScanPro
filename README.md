# 前言
`MCScanPro` 是一个基于 Python 和 Tkinter 的轻量级桌面应用，专为 Minecraft 玩家和服务器管理员设计。它能够高效地批量扫描多个 IP 地址和端口范围，快速发现在线的 Java 版和基岩版 Minecraft 服务器。

这个工具利用了 `mcstatus` 库，能够获取服务器的版本、在线玩家数以及服务器描述等详细信息，并以简洁清晰的方式展示结果。

## 功能特性

  * **多 IP/域名扫描**：支持批量输入多个 IP 地址或域名，每行一个。
  * **端口范围扫描**：自定义端口扫描范围，例如 `20000-25000`。
  * **多版本支持**：可选择同时扫描 Java 版和基岩版服务器。
  * **高并发性能**：支持自定义并发数，加快扫描速度。
  * **实时结果展示**：扫描结果会实时显示在 GUI 界面上。
  * **结果保存**：所有扫描到的在线服务器信息都会自动保存到 `scan_results.txt` 文件中。
  * **简洁 GUI**：直观易用的图形用户界面，无需命令行操作。

## 使用方法

### 1\. 安装依赖

如果你希望从源代码运行此程序，请确保你已经安装了 Python 3.x，并通过 pip 安装所需的库：

```bash
pip install mcstatus
pip install tk
```

### 2\. 运行程序

下载 `mc.py` 文件后，在命令行中执行以下命令即可启动程序：

```bash
python mc.py
```

### 3\. 界面操作

  * 在“目标IP/域名”文本框中，输入要扫描的 IP 或域名，每行一个。
  * 在“端口范围”中，输入你想要扫描的端口范围，例如 `20000-25000`。
  * 勾选你想要扫描的 Minecraft 版本（Java 或基岩）。
  * 设置“最大并发数”以控制扫描速度。
  * 点击“开始扫描”按钮，程序将开始工作，并在下方实时显示结果。

### 4\. 获取可执行文件 (EXE)

为了方便非 Python 用户，你可以使用打包好的 `MCScanPro.exe` 文件。你可以在项目的 [Release 页面](https://www.google.com/search?q=%E9%93%BE%E6%8E%A5%E5%88%B0%E4%BD%A0%E7%9A%84Release%E9%A1%B5%E9%9D%A2) 下载最新版本。
